## 🛠️ Решение проблемы

### Вариант 1: Выполнить декомпиляцию вручную

1. Откройте командную строку
2. Перейдите в директорию проекта:
   ```cmd
   cd C:\Users\abobn\OneDrive\7496~1\semaphore\semaphore\mcp-rimworld-dll-search
   ```

3. Проверьте путь к RimWorld:
   ```cmd
   set RIMWORLD_PATH=C:/Program Files (x86)/Steam/steamapps/common/RimWorld
   ```
   (Или укажите ваш путь, если RimWorld установлен в другом месте)

4. Выполните декомпиляцию:
   ```cmd
   npm run decompile
   ```

### Вариант 2: Использовать диагностический скрипт

Запустите созданный скрипт проверки:
```cmd
cd C:\Users\abobn\OneDrive\7496~1\semaphore\semaphore
check-mcp-connection.bat
```

Скрипт проверит:
- Существование проекта
- Структуру файлов
- Наличие декомпилированных файлов
- Путь к RimWorld
- Установку .NET SDK и ILSpy CLI
- Конфигурацию Cursor

### Вариант 3: Проверить путь к RimWorld

Если RimWorld установлен не в стандартном месте, нужно:

1. Найти путь к RimWorld (обычно в Steam):
   ```
   C:/Program Files (x86)/Steam/steamapps/common/RimWorld
   ```
   или
   ```
   D:/Steam/steamapps/common/RimWorld
   ```

2. Обновить конфигурацию Cursor:
   - Откройте: `C:\Users\abobn\AppData\Roaming\Cursor\User\globalStorage\saoudrizwan.claude-dev\settings\cline_mcp_settings.json`
   - Измените `RIMWORLD_PATH` на правильный путь
   - Перезапустите Cursor

3. Или установите переменную окружения перед декомпиляцией:
   ```cmd
   set RIMWORLD_PATH=ваш_путь_к_RimWorld
   npm run decompile
   ```

## 📝 Примечания

- Код ошибки декомпиляции `2147516566` может указывать на проблему с:
  - Путем к RimWorld
  - Правами доступа к файлам
  - Отсутствием Assembly-CSharp.dll
  - Проблемами с ILSpy CLI

- Декомпиляция может занять несколько минут в зависимости от размера Assembly-CSharp.dll

- После успешной декомпиляции папка `decompile` должна содержать множество .cs файлов
