# Настройка MCP сервера Rimworld для помощи в игре

## Что может делать MCP сервер для Rimworld?

MCP сервер `mcp-rimworld-dll-search` позволяет:
- **Искать функции и классы** в декомпилированном коде Rimworld
- **Изучать механику игры** через исходный код
- **Находить функции для создания модов** с Harmony патчами
- **Получать информацию о классах** и их методах
- **Анализировать игровую логику** для понимания работы игры

## Предварительные требования

1. ✅ MCP сервер установлен (см. `MCP_RIMWORLD_INSTALL.md`)
2. ✅ .NET SDK установлен
3. ✅ ILSpy CLI установлен
4. ✅ Декомпиляция выполнена (`npm run decompile`)

## Настройка MCP сервера в Cursor

### Шаг 1: Найдите конфигурационный файл Cursor

Конфигурация MCP серверов в Cursor обычно находится в одном из следующих мест:

**Windows:**
- `%APPDATA%\Cursor\User\globalStorage\saoudrizwan.claude-dev\settings\cline_mcp_settings.json`
- Или через настройки Cursor: `File > Preferences > Settings > MCP Servers`

### Шаг 2: Добавьте конфигурацию MCP сервера

Добавьте следующую конфигурацию в файл настроек MCP:

```json
{
  "mcpServers": {
    "rimworld-dll-search": {
      "command": "node",
      "args": [
        "C:\\Users\\abobn\\OneDrive\\7496~1\\semaphore\\semaphore\\mcp-rimworld-dll-search\\build\\index.js"
      ],
      "cwd": "C:\\Users\\abobn\\OneDrive\\7496~1\\semaphore\\semaphore\\mcp-rimworld-dll-search",
      "env": {
        "RIMWORLD_PATH": "C:/Program Files (x86)/Steam/steamapps/common/RimWorld"
      }
    }
  }
}
```

**Важно:** 
- Замените путь на актуальный путь к вашему проекту
- Если RimWorld установлен в другом месте, измените `RIMWORLD_PATH`

### Шаг 3: Перезапустите Cursor

После добавления конфигурации перезапустите Cursor, чтобы MCP сервер подключился.

   ```

   ```

### Доступные инструменты MCP сервера

После настройки в Cursor будут доступны следующие инструменты:

#### 1. `search` - Поиск функций
**Параметры:**
- `searchTerm` (обязательно) - Термин для поиска
- `includePrivate` (опционально) - Включать приватные методы (по умолчанию: false)
- `limit` (опционально) - Лимит результатов (по умолчанию: 10)

**Пример использования:**
```
Используй инструмент search с параметрами:
- searchTerm: "DamageInfo"
- includePrivate: false
- limit: 5
```

#### 2. `getFullContent` - Получить полный код файла
**Параметры:**
- `filePath` (обязательно) - Путь к файлу из результатов поиска

**Пример использования:**
```
Используй инструмент getFullContent с параметром:
- filePath: "decompile/Assembly-CSharp/Verse/DamageInfo.cs"
```

## Устранение проблем

### Проблема: MCP сервер не подключается в Cursor

**Решения:**
1. Проверьте путь к `build/index.js` - файл должен существовать
2. Убедитесь, что выполнена декомпиляция (`npm run decompile`)
3. Проверьте синтаксис JSON в конфигурации
4. Перезапустите Cursor
5. Проверьте логи Cursor на наличие ошибок

### Проблема: Инструменты не доступны

**Решения:**
1. Убедитесь, что MCP сервер запущен
2. Проверьте конфигурацию в настройках Cursor
3. Попробуйте перезапустить MCP сервер

### Проблема: Поиск не находит результаты

**Решения:**
1. Убедитесь, что декомпиляция выполнена успешно
2. Проверьте, что папка `decompile` существует и содержит файлы
3. Попробуйте более общие термины поиска

## Дополнительные возможности

### Использование через CLI

Вы также можете использовать MCP сервер напрямую через командную строку:

```cmd
cd mcp-rimworld-dll-search
node build/stdioTest.js
```

Затем используйте команды:
- `search <term> [private=true|false] [limit=number]` - Поиск функций
- `show <filePath>` - Показать содержимое файла
- `help` - Справка
- `exit` - Выход
