## ❓ Устранение проблем

### MCP сервер не подключается

1. Проверьте, что файл конфигурации существует:
   ```
   C:\Users\abobn\AppData\Roaming\Cursor\User\globalStorage\saoudrizwan.claude-dev\settings\cline_mcp_settings.json
   ```

2. Проверьте синтаксис JSON (должен быть валидным)

3. Убедитесь, что путь к `build\index.js` правильный

4. Перезапустите Cursor

### Поиск не работает

1. Убедитесь, что декомпиляция выполнена (папка `decompile` существует)

2. Попробуйте более общие термины поиска

3. Проверьте, что RimWorld установлен и путь правильный

### Ошибки при запуске

Если видите ошибки, проверьте:
- Node.js установлен: `node --version`
- .NET SDK установлен: `dotnet --version`
- ILSpy CLI установлен: `ilspycmd --version`
